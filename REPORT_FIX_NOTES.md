# Виправлення звітів
- Форма №1: однакова ширина 4 стовпців активу і пасиву.
- Форма №2: ті самі правила для таблиці.
- Довгі назви переносяться, числові стовпці вирівняні.
- PDF фінансових звітів: окремий макет шириною 720 px, A4 portrait, 8 мм поля, початок наступної форми з нової сторінки.
- Не змінювались формули та дані.
- Увага: це виправлення верстки, а не сертифікація відповідності нормативним бланкам. Наразі форми показують гривні, тоді як офіційна звітність може вимагати тис. грн та додаткові реквізити.
