# Оновлення ProOblik — 20.11.2026

## Фінансова звітність
- Для фінансових форм PDF відкривається спеціальний ізольований макет A4 у новому вікні. У діалозі друку оберіть «Зберегти як PDF». Цей шлях не використовує html2canvas, який обрізав ліві стовпці.
- Excel експортується в окремі аркуші «Актив», «Пасив», «Форма 2», з більшими ширинами і шапкою підприємства. Обмеження: XLSX-бібліотека без розширень не гарантує складне форматування й автоперенесення тексту.
- Реквізити фінансової звітності введені в налаштуваннях підприємства. ПІБ керівника, головного бухгалтера, фіндиректора та керівника кадрів вибираються з «Персоналу».
- Важливо: повна нормативна верифікація всіх кодів, бухгалтерських формул і передбачених законом варіантів форм №1/2 та №1-м/2-м не завершена. PDF є друкованим макетом; це не файл електронної податкової звітності.

## Довідники
- Персонал: група, ПСП так/ні, відсоток ПСП, кількість дітей, ставка ЄСВ.
- Покупці та постачальники: групи з фільтром, пошук.
- Номенклатура: артикул, штрихкод, група; пошук за назвою, кодом, артикулом.
- Дані зберігаються у наявній таблиці `refs.data` (без міграції цих реквізитів). Штрихкод перевіряється на дублікати в UI поточного підприємства; для конкурентних записів бажаний окремий унікальний індекс у БД.

## Зарплата
- Нова сторінка «Податкові нормативи» з полями за роками (початкові значення 2026: 3328 та 8647 грн; перед використанням підтвердити).
- Нова сторінка «Нарахування зарплати»: нарахована сума, ПДФО 18%, військовий збір 5%, обмежений ПСП, додаткові утримання, до виплати, ЄСВ роботодавця.
- На сервері повторний розрахунок і збереження в `payroll_calculations`, унікально на працівника та місяць. Дія записується в audit_log. Бухгалтерські проводки НЕ створюються автоматично.
- Загальний поріг ПСП: прожитковий мінімум на 01.01 ×1,4, округлення до 10 грн. Стандартна ПСП = 50% прожиткового мінімуму × коефіцієнт 100/150/200%. ПСП не зменшує базу ВЗ.
- Підвищені межі доходу для певних дитячих пільг, обмеження декількох роботодавців, окремі пільгові ставки ЄСВ, спеціальні випадки й відповідність заяві на ПСП автоматично не перевіряються — потрібен бухгалтерський контроль.
- Для ЄСВ мінімальна база застосовується лише коли вручну встановлено прапорець «основне місце, повний місяць»; максимальна база 20×мінімальна зарплата. За особливих ставок/категорій перевірка умов залишається за бухгалтером.

## Порядок установки
1. Зробити резервну копію Neon.
2. Запустити `payroll_migration.sql` через Neon SQL Editor.
3. Замінити файли GitHub і задеплоїти Netlify.
4. Перевірити «Довідники → Податкові нормативи», «Персонал», «Номенклатура» й «Операції → Нарахування зарплати».
5. Заповнити реквізити підприємства, сформувати форми №1,2 та зберегти їх через друк у PDF.

## Тестування
Синтаксис усіх JS перевірено. Інтеграційні тести з живою базою Neon/Netlify не виконувалися. Не використовувати як підтверджену електронну звітність до додаткової перевірки.
