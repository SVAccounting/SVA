# Сканування штрихкодів у ProOblik

У **Довідники → Номенклатура** біля поля «Штрихкод / код» додано кнопку 📷. Натисніть її, дозвольте доступ до камери та наведіть пристрій на штрихкод. Зчитане значення вставляється в поле; збереження картки виконується окремо кнопкою «Зберегти». Також є вибір фото з камери або файлової системи.

Реалізація використовує бібліотеку `html5-qrcode` 2.3.8 із CDN jsDelivr, яка підвантажується лише при відкритті сканера. Для роботи потрібні HTTPS та дозвіл користувача на камеру, а для першого завантаження бібліотеки — інтернет. На різних браузерах сумісність і розпізнавання форматів можуть відрізнятися. Камера зупиняється після успішного зчитування або закриття вікна.

Код передається тільки в поле форми та далі зберігається через наявний API після підтвердження користувача. Існуючий захист від дублювання штрихкодів у межах завантаженої номенклатури збережено. Для надійної заборони дублювання між різними сесіями також потрібна серверна перевірка.

SQL-міграції не потрібні. Синтаксис JavaScript перевірено; фактичну роботу камери слід перевірити на телефоні через розгорнутий HTTPS-сайт.
