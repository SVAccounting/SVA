# Оновлення навігації і плиток
- Початковий `boot()` перенесено після завантаження app7/app8, основний екран — `home`.
- Після вибору підприємства — робочий стіл, не журнал.
- Плитки мають реальні символи-іконки і лише один підпис, без дублювання першого слова.
- Автозбереження кожні 180 секунд з локальними чернетками форм, перемикач і кнопка примусового збереження на робочому столі. Не проводить бухгалтерські документи і не зберігає на сервері.
- Параметри limit та offset (1..1000) додано для API списків entries/docs, але старі виклики без параметрів повертають усі рядки для сумісності зі звітами.
- Для повноцінної серверної пагінації інтерфейсу журналів потрібна окрема зміна клієнтського коду.
